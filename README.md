# byrishav.online — Personal Portfolio

A high-performance portfolio website built with **Next.js 16**, **Tailwind CSS 4**, and **Framer Motion**. Deployed on **Vercel**.

## Live Site

[byrishav.online](https://byrishav.online)

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion + Lenis smooth scroll
- **Icons**: Lucide React
- **Deployment**: Vercel
- **Domain**: Hostinger

## Features

- Scroll-linked parallax hero with mouse tilt
- Interactive project case studies
- Kinetic background grid
- Command menu (⌘K)
- Fully responsive design
- SEO optimized with structured data (JSON-LD)
- OG image and Twitter cards
- Sitemap and robots.txt

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
